# Карта сайта ashpartners.ru

Один файл `site/index.html`: вся разметка, весь CSS (в `<style>` в `<head>`),
весь JS (в `<script>` перед `</body>`). Секции идут в порядке ниже.
Номера в комментариях `<!-- NN ─ Название -->` в самом HTML соответствуют
этому списку — искать по ним (`grep -n "<!-- " site/index.html`).

**Живой сайт (GitHub Pages, деплоится автоматически при пуше в `main`):**
`https://alina3500-2-arch.github.io/project-s-sashey/`
Деплой — `.github/workflows/pages.yml`, публикует папку `site/` как корень.

Превью-инструмент для проверки ПК-версии с телефона:
`https://alina3500-2-arch.github.io/project-s-sashey/site/pc.html`

## Кто где правил

Сайт правился из двух разных инструментов в одном репозитории — Claude Code
(этот чат и его предшественники) и Codex. **Кейс Eco-Store, часть фото
(hero, лестница, портрет Алины) и сама публикация через GitHub Pages —
последняя крупная работа сделана в Codex** (см. `git log --oneline main`,
коммиты `4b95f36`, `996538e`). Если начинаешь новую сессию — сначала
`git fetch origin main` и сверить, что нет новых чужих коммитов, прежде
чем предполагать, что тут описано актуальное состояние.

## Кейс Eco-Store (блок 05) — актуальная структура

Полностью пересобран в Codex поверх моего первого варианта. Теперь **5
вкладок**, переключаются через `.cb-tabs` / `.cb-frame[data-panel]`
(`data-panel="0"`…`"4"`), JS в конце файла (`var cbTabs = ...`):

| panel | Название | Как сделано |
|---|---|---|
| 0 | Обложка (`cb-cover`) | Живая вёрстка `.case-cover-*`, не картинка |
| 1 | 01 / Анализ | `.case-analysis-grid`, текст живой + фото `case-analysis-desk.jpg` |
| 2 | 02 / Упаковка (`cb-pack`) | Живая вёрстка `.case-pack-grid`, было/стало сайта: `case-old-site.png` / `case-new-site.png`. **Раньше этого слайда не было вообще — теперь есть.** |
| 3 | 03 / Трафик | `.case-traffic-grid`, таблицы до/после — живой HTML (не картинка), реальные цифры оборота |
| 4 | 04 / Система | `.case-system-grid`, список Bitrix24/КП-калькулятор/Производство/Обучение живым текстом + фото `case-system-tools.jpg` |

Важное отличие от моей первой версии: **текст теперь редактируется как
обычный HTML**, не встроен в растр. Это значит правки текста внутри кейса
(если попросят) — дёшево, без пиксельного подбора шрифтов. Старые файлы
`case-analysis.jpg`, `case-traffic.jpg`, `case-system.jpg` (мои
слайды-картинки из первой версии) в `site/assets/` остались физически, но
**больше не используются** в разметке — можно удалить при уборке, но не
трогать без необходимости (не мешают).

Слайд про B2B-логистику по-прежнему нигде не использован — если понадобится,
уточнить у пользователя, куда его пристроить (это другой клиент).

## Git

`main` — единственная активная ветка, GitHub Pages публикует её
автоматически при пуше (`paths: site/**`). Отдельная ветка
`claude/website-structure-content-pottmu`, которая раньше фастфорвардилась
в `main`, дальше **не обязательно использовать** — начиная с этой сессии
можно коммитить прямо в `main`, но **всегда `git fetch origin main`
и сравнить перед push**, потому что правки идут из нескольких инструментов
параллельно.
