# PÉRFECT TON by Diana Fedorova — прототип сайта

Статический прототип, 8 разделов — **отдельными вкладками** (страницами),
как просили, а не одним лендингом:

| Файл | Вкладка |
|---|---|
| `index.html` | Главная |
| `about.html` | О студии |
| `services.html` | Услуги |
| `podology.html` | Подология |
| `price.html` | Прайс |
| `portfolio.html` | Работы |
| `reviews.html` | Отзывы |
| `contacts.html` | Контакты и запись |

Стили — `diana.css`, скрипты — `diana.js` (мобильное меню, подсветка вкладки,
заглушка отправки формы). Референс по духу — prive7.com: тёмный фон, тонкая
разрядка, много воздуха, крупные фото-блоки. Палитра из брендбука Дианы:
`#312322` (горький шоколад), `#aa998a` (бежевый), `#ffffff`. Шрифт — Jost
(ближайший бесплатный аналог Room из брендбука).

## Что осознанно не заполнено

Цены, телефон, адрес, отзывы, тексты о Диане и фото — **плейсхолдеры с
пометками**. Ничего не выдумано: нужны реальные данные от Дианы.
Список запросов вынесен в блоки «Нужно от Дианы» на страницах.

## Локальный просмотр

```
cd diana && python3 -m http.server 8899
```
